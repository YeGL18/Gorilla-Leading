# 泊車、樓層、音效及重開機手動驗收

更新日期：2026-10-04。下列方格留空，代表仍需真機手動驗證；自動測試通過不代表氣壓計、車機藍牙或 iOS 通知已完成實地驗證。

## 已改動的邏輯

| 範圍 | 現在的做法 |
| --- | --- |
| 地點與樓層 | 設定可切換「每個地點固定樓層」與「相同地點不同樓層」。預設保留固定樓層模式，切換不會合併、刪除或重寫歷史記錄。 |
| 同位置不同設施 | G/F 上落客區及 B1 住戶停車場可設定各自「歸納樓層」；跨 B3/B4 的同一停車場選「所有樓層」。未知樓層遇到多個候選設施時，不強行歸類。 |
| 樓層校準 | 保存每次泊車的樓層及相對高度變化；不再把同一地點鎖死為唯一樓層。只用明確手動確認的資料學習；改一次不改寫其他到訪。 |
| 樓層差異確認 | 與上次手動確認不同時，可選「這次停另一樓層」，或明確修正指定上次記錄，不會批量覆蓋。 |
| 地圖顯示 | 相同停車區域與樓層的記錄聚成一點，顯示記錄數量；重疊樓層點只在畫面中分開，不再移動地理座標。最新群組維持放大 30%。選中後顯示該區域共用的圓形範圍。 |
| 歷史修正 | 膠囊「停車記錄」開原生清單，可查看此樓層或所有樓層、選取單次記錄或批次修正樓層。改樓層即重新聚類，空群組消失，不新增停車場、不搬動 GPS。估算與人手確認分開顯示。 |
| 氣壓採樣 | 前景中先行車達 20 km/h，再降至 20 以下開始；不做全程低速短途方案，不在背景持續採樣。 |
| 閘機與停泊 | 同一條曲線連續採樣；停定頭 8 秒提示短暫停頓，之後確認停泊。穩定停定 10 秒只詢問，不自行關閉感測器；未確認則每隔 10 秒再問。 |
| 停止與選樓層 | 確認泊好或符合條件的已選車機藍牙斷線才凍結結果；之後可調樓層，改數字即保存，毋須先按剔號。閒置 10 秒後有 3 秒描邊倒數、自動剔號及收起動畫。 |
| 採樣起點 | 預設起點為 G；如果實際已在其他樓層，可更改起點，避免把相對下降高度當成絕對樓層。氣壓計仍可能受風壓影響，不保證每次準確。 |
| 音效 | 保留樓層探測展開／鎖定音效，沒有新增每個樓層專屬音效。啟動聲可選原有或 2；逗留／開車新舊聲成組切換；泊車時間提醒使用獨立聲。 |
| 實際泊車時間 | 到訪與停車點使用實際到達時間，樓層結果按到達事件和位置配對。泊車記憶的付款時間可手動加減，但不會改寫停車點建立時間或實際泊車開始時間。 |
| 開機與語言 | 等 iOS 保護資料可讀後，先載入目的地、泊車記錄及預測，再啟動主畫面／定位。尊重 iOS 個別 App 語言，不再刪除或改寫 AppleLanguages；同步語言到實時活動。 |
| 本輪 UI | 咪錶設定下移、目的地預設摺疊、光球配色搬到光球效果、膠囊動畫「預設」改名「標準」。行車追蹤點下移 60pt。首頁搜尋分類改開原生可捲動列表。 |

## Checklist

請停車後由乘客或本人安全操作，不要一邊駕駛一邊測試。更新前不要刪除 App；重新開機測試不需要刻意耗盡電池。

| 完成 | 手動操作 | 應見結果 |
| --- | --- | --- |
| [ ] | 選啟動音效 2，關閉再啟動 App；再切回原有聲 | 各自聲音正確，新聲完整播放，不在約 3 秒被截斷；設定可保留。 |
| [ ] | 逗留／開車選原有 → 新 → 原有，逐一試聽 | 兩個狀態一起換版本，沒有新舊混用，無須重開 App。 |
| [ ] | 泊車至 25 分鐘提醒，再測試到達／離開通知 | 時間提醒播新獨立聲，不混用到達／離開通知聲；須允許通知聲並檢查靜音／專注模式。 |
| [ ] | 開設定，再展開目的地 | 初次只顯示目的地列及數量；展開後可選取、改名、刪除及新增。咪錶拉桿不再位於設定最頂。 |
| [ ] | 在光球效果選配色；檢查膠囊動畫選項 | 配色仍生效；選項是「標準／提升縮放」，原有選擇及預設提升縮放不被重設。 |
| [ ] | 首頁「尋找地點」選我的目的地，準備足夠多地點 | 上下捲動到最尾仍可點選；搜尋能找到指定地點，選取後原有 ETA／路線會更新。 |
| [ ] | 橫屏重複上一項；再試停車場、學習地點及 Duo toolbar | 每類只顯示該類，全部項目可捲動，取消不改目的地，長名字不被裁斷。 |
| [ ] | 駕車達 20 以上再降至 20 以下，保持 App 在前景 | 自動顯示樓層探測並開始採樣；正常高速時不持續收集氣壓。 |
| [ ] | 閘前停 8 秒，再低速前進 | 短暫停頓倒數有數字動畫；前進後「經過閘機」約 3 秒，曲線連續、不重開感測器。 |
| [ ] | 閘前等超過 10 秒，選未泊好或不操作 | 採樣持續；約 10 秒再詢問，不因等閘凍結樓層；前進會取消舊詢問。 |
| [ ] | 真正停好後確認泊好 | 採樣停止、曲線凍結，顯示可調樓層；之後走路／坐升降機不再改動泊車樓層。 |
| [ ] | 已選我的車機，測試車機斷線；另試耳機斷線 | 合適的車機斷線可結束捕捉；耳機／其他裝置不應當成泊車證據。 |
| [ ] | 調樓層但不按剔號；另一次完全不操作 | 改數字立即保存；閒置 10 秒後剔號放大、3 秒描邊倒數、自動確認動畫，結果保留。 |
| [ ] | 採樣時切到背景，再回 App | 背景停止採樣，不把背景空白期間或重新取到的高度接成假的連續曲線。 |
| [ ] | 起點實際為 B3，更改起點，再到 B4 | 以 B3 為基準，下降一層結果應接近 B4，而不是錯當成 B1。 |
| [ ] | 開不同樓層模式，同一停車場先 B3 後 B4，手動確認 | 兩次各自保留，B4 不會被固定成 B3；選「這次停另一樓層」不改上次。 |
| [ ] | 對已知錯的上次記錄，選一併修正 | 只修改提示中的指定上次記錄，其他到訪不變；同一次反覆修改不重複累加學習樣本。 |
| [ ] | 同座標設定 G 上落客區與 B1 住戶車場的歸納樓層 | 有已知樓層時按樓層歸類；未知時不隨機選其中一個，手動選的車場不被遲到的結果覆蓋。 |
| [ ] | 地圖查看重疊不同樓層群組，選一筆歷史記錄再輕微拖動其點 | 可分辨樓層群組，拖動只更新所選記錄；管理頁與導航使用真實位置，不保存畫面顯示偏移。 |
| [ ] | 同一車場準備四次 B1、兩次 B2 記錄，開不同樓層模式 | 顯示 B1（4 次）與 B2（2 次）；各筆時間、照片、車位仍分開保存，選中任一群組使用同一區域邊界。 |
| [ ] | 從 B2 群組的停車記錄清單選一筆，修正成 B1 | B1 變五次、B2 變一次，只改所選記錄，不改其他樓層或座標。 |
| [ ] | 顯示所有樓層，選取餘下 B2 記錄批次修正成 B1 | 確認對話框顯示正確筆數；B2 空群組消失，B1 合為六次，重開 App 後仍一致。 |
| [ ] | 對估算樓層按剔號確認；另一次只等自動收起 | 人手確認標記為已確認並可參與學習；未操作的估算不當作人手確認或訓練樣本。 |
| [ ] | 停車記錄清單有 50 筆，在手機橫／豎屏捲到最尾再選取 | 清單可完整捲動；返回既有膠囊時顯示所選歷史記錄，並能單獨更改樓層或停車場。 |
| [ ] | 不同樓層與固定樓層模式來回切換 | 舊資料及各次手動樓層仍在；樓層命名同步地圖、到訪與當次實時活動。 |
| [ ] | 泊好後把付款時間加減數分鐘，再看到訪／地點管理／樓層 | 停車點建立時間及實際到達事件不變，樓層不錯配另一個點；付款時間與實際時間刻意分開。 |
| [ ] | 到達新地點後改舊地點名稱 | 當前實時活動仍是新地點泊車中，舊記錄可改名但不搶走當前泊車狀態。 |
| [ ] | 系統英文、App 繁中；記低目的地與最新記錄，重開機解鎖再開 App | 不用重新勾語言，設定仍為繁中，目的地、選中目的地、泊車記錄及新舊音效選擇仍在。 |
| [ ] | 重複重開 App／切背景；再選簡中、日文、英文 | 介面與設定顯示一致，不出現新安裝流程或空白資料覆蓋舊資料；實時活動更新後語言一致。 |
| [ ] | 乘客安全觀察行車追蹤，並用單指移動地圖 | 追蹤點比原先再下移 20pt，總計 60pt；行車高度維持 1800m，手動瀏覽仍可即刻接管。 |

## 自動驗證入口

- `ruby Tests/SFXPreferenceChecks.rb`：音效選擇持久化、成組切換、原有檔案及通知聲格式／時長。
- `ruby Tests/ParkingAltitudeChecks.rb`、`ruby Tests/ParkingSessionChecks.rb`：連續採樣、延後確認、閘機、凍結結果。
- `ruby Tests/ParkingLevelChecks.rb`：不同樓層、歷史保留、校準、設施歸類、純顯示偏移。
- `ruby Tests/ParkingEntryClockChecks.rb`：付款時間調整、重開 App、Live Activity 及 widget 共用計時基準，不改實際到達時間。
- `Tests/ParkingRecordUIProject.rb` + `Tests/ParkingRecordUITests.swift`：獨立測試 App 的原生歷史清單、橫／豎屏捲動及批次樓層修正。
- `ruby Tests/VisitHistoryChecks.rb`：到訪時間窗口、行程分段及歷史改名不覆蓋當前泊車。
- `Tests/LanguageMigrationChecks.swift`：保留系統 App 語言與原有資料。
- `Tests/SettingsSearchUIProject.rb` + `Tests/SettingsSearchUITests.swift`：獨立測試 App 的長列表捲動、搜尋、選取及日文音效設定；不使用主 App 儲存資料。

通知聲轉為 PCM CAF：iOS 官方要求自訂通知音使用 AIFF/WAV/CAF，且少於 30 秒。來源：https://developer.apple.com/documentation/usernotifications/unnotificationsound
